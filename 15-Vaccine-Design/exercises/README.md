# Module 15 Exercises: Vaccine Design

### Exercise 15.1: SARS-CoV-2 Spike Epitope Conservation & HLA Population Coverage
- **Objective**: Scan the Spike glycoprotein across ancestral and variant strains (Omicron, Delta) to identify 9-mer CD8+ T-cell epitopes with > 90% population coverage across diverse ethnic HLA alleles using IEDB population coverage metrics.

### Exercise 15.2: mRNA Secondary Structure Optimization (LinearDesign Replication)
- **Objective**: Implement a dynamic programming lattice algorithm to find the mRNA sequence encoding a specified antigen peptide that minimizes folding free energy ($\Delta G$) while maximizing Codon Adaptation Index (CAI).
