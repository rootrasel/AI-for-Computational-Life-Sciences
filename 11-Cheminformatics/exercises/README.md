### Exercise 11.1: Bemis-Murcko Scaffold Splitter
- **Objective**: Implement Bemis-Murcko core extraction and split a dataset into train/validation/test (80/10/10) such that NO scaffold present in train appears in test.
- **Comparison**: Compare random split vs scaffold split validation performance on a QSAR binding affinity regressor.
