# Module 17 Exercises: Pharmaceutical AI

### Exercise 17.1: L1000 Signature Reversal for Cancer Drug Repurposing
- **Objective**: Given differential expression signatures from TCGA glioblastoma vs healthy tissue, query LINCS L1000 perturbational profiles to identify top small molecule repurposing candidates.

### Exercise 17.2: Propensity Score Matching for Synthetic Control Arms
- **Objective**: Implement nearest-neighbor and caliper-based propensity score matching to balance baseline covariates between treated and synthetic historical control cohorts, evaluating post-match Standardized Mean Difference (SMD < 0.1).
