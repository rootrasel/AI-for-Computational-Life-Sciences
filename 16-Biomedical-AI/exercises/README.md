# Module 16 Exercises: Biomedical AI

### Exercise 16.1: PrimeKG Relational Graph Convolutional Network (R-GCN)
- **Objective**: Build an R-GCN link prediction model on a PrimeKG subgraph to predict novel drug indication edges (`drug_treats_disease`).
- **Evaluation**: Report Hits@10, Hits@1, and Mean Reciprocal Rank (MRR) with filtered ranking protocol.
