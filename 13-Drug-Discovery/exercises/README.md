# Module 13 Exercises: Computer-Aided Drug Discovery

### Exercise 13.1: Complete DUD-E Benchmark Virtual Screening Pipeline
- **Objective**: Run virtual screening on the DUD-E EGFR target using AutoDock Vina.
- **Task**: Dock 50 active ligands and 500 decoys, compute docking scores, and generate ROC curves with $EF_{1\%}$ and BEDROC evaluation.

### Exercise 13.2: Graph Neural Network for hERG Cardiotoxicity Prediction
- **Objective**: Implement a PyTorch Geometric Graph Convolutional Network (GCN) taking molecular graphs with atom features and edge attributes to predict hERG channel blocking probability from Therapeutics Data Commons (TDC).
