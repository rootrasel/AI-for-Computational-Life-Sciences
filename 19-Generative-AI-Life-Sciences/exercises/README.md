# Module 19 Exercises: Generative AI for Life Sciences

### Exercise 19.1: Pocket-Conditioned 3D Molecular Diffusion (Mini-TargetDiff)
- **Objective**: Implement an equivariant diffusion reverse process denoising a cloud of 20 ligand atoms inside a rigid protein binding pocket grid.
- **Evaluation**: Assess validity, steric clash rate, and internal bond length distribution against reference ChEMBL distributions.

### Exercise 19.2: SE(3) Rigid Frame Diffusion for Protein Backbones
- **Objective**: Implement frame-based diffusion on $SE(3)$ (translation vector $t \in \mathbb{R}^3$ and rotation matrix $R \in SO(3)$) using Rodrigues formula to generate 50-residue de novo unconditioned protein backbones.
