# Module 05 Exercises: Quantitative Proteomics

### Exercise 5.1: Target-Decoy Search Engine & False Discovery Rate (FDR) Controller
- **Objective**: Implement a reversed-sequence decoy database generator.
- **Task**: For a synthetic tandem mass spectrum dataset, compute hyperscore matches against both target and decoy proteins, rank matches, and compute the 1% PSM-level and protein-level FDR cutoff.

### Exercise 5.2: Label-Free Quantification (LFQ) Missing-Value Imputer
- **Objective**: Implement the MaxLFQ peptide-to-protein ratio graph solver and test missing-value imputation strategies (QRILC vs MinDet) on quantitative DIA proteomics matrices.
