# Module 08 Exercises: Systems Biology

### Exercise 8.1: Genome-Scale Gene Essentiality Screening with COBRApy
- **Objective**: Load the `iJO1366` or `e_coli_core` model and perform single-gene knockout deletion screens.
- **Task**: Identify all essential genes under glucose minimal vs rich media conditions and evaluate metabolic pathway redundancies.

### Exercise 8.2: Disease Module Identification via Random Walk with Restart (RWR)
- **Objective**: Given a set of seed disease risk genes from GWAS, implement RWR on the human STRING interactome network to discover topologically cohesive disease modules.
